01 PROJECT OVERVIEW

From a simple RC car to a smart vehicle.

This project combines embedded programming, wireless communication, sensors and motor control into a single working robotic platform.

01 SMART ROBOTIC VEHICLE
ABOUT THE PROJECT

A hardware project focused on intelligent movement and sensing.

The vehicle can be controlled wirelessly using a smartphone through an HC-05 Bluetooth module. Commands are processed by an Arduino Uno and converted into motor actions through the L298N motor driver.

Ultrasonic sensors continuously monitor the surrounding environment and provide distance information to the controller.

Bluetooth wireless control
Obstacle detection
Servo-based sensor movement
DC motor direction control
LED and buzzer indicators

05 — SYSTEM WORKFLOW

How the car works.

From a smartphone command to physical movement, the system passes through multiple control layers.

01
INPUT

Smartphone Command

The user sends movement commands such as forward, backward, left or right.

02
COMMUNICATION

Bluetooth Transfer

HC-05 receives the wireless command and transfers it to Arduino.

03
PROCESSING

Arduino Decision

Arduino processes the command together with sensor information.

04
SENSING

Obstacle Detection

Ultrasonic sensors measure the distance between the vehicle and nearby objects.

05
OUTPUT

Motor Movement

L298N receives control signals and drives the motors according to the decision.
